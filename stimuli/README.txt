Here is the description of the folders' organization.

There is 3 folders, for each Experiment. Each folder contained 2 folders, for each type of stimuli used in the Experiment.
	- Exp1: original and phase-scramble.
	- Exp2: grayscale and grayscale phase-scramble.
	- Exp3: grayscale and texforms.

In each type of stimuli folders are 2 other folders, one for each category:
	- Animates_stimuli: contained 320 images of animates, and a folder, "Inanimates_Oddball", containing the exemplars used as oddball in the inanimate sequence.
	- Inanimates_stimuli: contained 320 images of inanimates, and a folder "Animates_Oddball", containing the exemplars used as oddball in the animate sequence.
